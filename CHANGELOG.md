# Changelog

## 0.3.1 — 2026-10-05

- Native Treasure Shuffle with mandatory original-progression protection,
  Balanced/Surprise styles and optional chest heart pieces.
- Deterministic seed recipes, import/export, spoiler logs and isolated seed saves.
- Online adventure selection with separate per-seed campaigns and exact asset
  hash matching; original adventures remain separate.
- Randomizer Guide topic and visible pinned launch actions.
- 1,000-seed protection checks, actual native chest/reward fixtures and clean
  package first-run/native seed launch validation.
- First public source repository and Windows preview release. Public packaging
  omits the unused upstream Switch icon containing a game sprite. Windows game
  binaries are unchanged by that source-resource cleanup.

## 0.3.0 — 2026-10-04

- Eight-player co-op protocol, eight cosmetic colors, Unicode names and roster.
- Shared permanent equipment/world progress and continued online campaigns.
- Optional 32-enemy-type shared combat beta, off by default.
- Guided host/join workflows and pinned connection actions.

## 0.2.2 — 2026-10-04

- Local MSU-1 soundtrack import/validation, selection and volume controls.
- Original music fallback, per-player selection and portable profile paths.

## 0.2.1 — 2026-10-03

- Visual keyboard/controller and engine-hotkey editor with capture, combinations,
  conflict handling, restore/discard and backed-up settings writes.

## Earlier local work

- Repaired the original launcher build flow and logs.
- Added the forest/gold Companion, smooth xBRZ preset, guided ROM setup, isolated
  campaigns, initial two-player presence and Internet hosting.

Historical checks and their limits are retained in [Validation.txt](Validation.txt).

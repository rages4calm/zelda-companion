# Security reporting

This is an experimental portable desktop application and private-room relay.
v0.3.1 is the current preview; no production hosting or security audit is claimed.

Use GitHub's **Report a vulnerability** entry in the repository Security tab for
suspected token disclosure, archive path traversal, unintended file writes or
network-input problems. If private reporting is unavailable, open a minimal
public issue asking for a private reporting channel, without exploit details,
secrets, ROMs or personal files.

Do not post room invitations, access tokens, raw personal logs or game data.
The room code grants access to an open slot. This experiment has no anti-cheat;
play with trusted people and keep backups before testing modified builds.

Source changes are checked through bounded protocol tests and payload audits.
Those checks are not a guarantee that all vulnerabilities are absent.
